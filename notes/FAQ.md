# FlyArena 常見問題與研究筆記

> 模擬交易實驗，非投資建議。數據整理於 2026-09-15，聯賽 survivors-2026。
> 前三名總結與淘汰報告見 [季賽報告](season-reports/)，產生方式：`python -m flyarena season-report survivors-2026`。

---

## 1. 修改檔案有沒有限制？

### 角色檔 `leagues/survivors-2026/profiles.json`

| 欄位 | 可以改嗎 | 說明 |
|---|---|---|
| `nickname` 暱稱、`title` 個性類型、`emoji`、`bio` 介紹 | ✅ | 改過就不會被每天的自動更新覆蓋；整行刪掉會恢復自動產生 |
| `avatar` 頭像 | ✅ | 填 `avatars/` 資料夾裡的檔名，例如 `"淺酌.png"`；`null` 使用自動生成的卡通果蠅 |
| `traits`、`family`、`gene`、`gene_note`、`_auto`、`control` | ❌ | 每天自動重算，改了也會被覆蓋 |

- 必須是**合法的 JSON**：少一個逗號或引號，雲端的每日更新就會失敗（GitHub 會寄信通知）。在 GitHub 網頁上編輯後，建議到 **Actions** 頁面確認下一次執行是綠色勾勾。
- 文字長度沒有硬性限制，但暱稱建議 2～6 個字，介紹 100 字以內，卡片版面才好看。

### 頭像圖片

| 項目 | 建議 |
|---|---|
| 格式 | png、jpg、webp、svg（gif 也能顯示） |
| 尺寸 | 正方形，256×256（網頁上最大顯示 96×96） |
| 檔案大小 | 每張 200 KB 以內；圖越大，網站載入越慢 |
| 版權 | 公開網站任何人都看得到，請用你有權使用的圖片 |

### GitHub 本身的上限

| 項目 | 上限 |
|---|---|
| 在 GitHub 網頁上傳單一檔案 | 25 MB |
| 用 git 推送單一檔案 | 超過 50 MB 會警告，超過 100 MB 會被拒絕 |
| Repository 大小 | 建議 1 GB 以下 |
| GitHub Pages 網站大小 | 1 GB |
| GitHub Pages 流量 | 每月約 100 GB（軟性上限） |
| GitHub Actions 單次執行 | 6 小時（我們每天約 1 分鐘） |
| 排程自動停用 | 公開 repository 連續 60 天沒有任何活動 |

目前整個 repository 約 1.5 MB，dashboard 網頁約 0.15 MB、每年大約增加 0.2 MB，離上限都非常遠。

### 不要手動改的檔案

- `leagues/survivors-2026/config.json`、`league.json`、`roster.json`、`brains/*.npz`：聯賽每天是**從開賽日重新播放**算出來的，改了這些，過去所有名次都會跟著改寫。想換規則請開新一屆聯賽（見第 3 節）。
- `docs/`：公開網站由雲端自動產生，手動改會在下一次更新時被覆蓋。
- 專案根目錄的 `arena.json` 可以隨意改，它只影響之後**新建立**的聯賽、淘汰賽與測試。

## 2. 家族繼承會繼承個性嗎？

**會，但只繼承一部分。** 果蠅的個性來自兩個來源：

| 來源 | 對應的個性 | 會遺傳嗎 |
|---|---|---|
| 大腦參數（學習速度、記憶痕跡、探索雜訊、KC 稀疏度） | 學習速度、記性、冒險心、專注 | ✅ 子代繼承親代參數，每項再隨機突變約 ±20% |
| 大腦接線（每顆 KC 接哪些感覺輸入） | 對哪些訊號敏感 | ✅ 繼承 98%，約 2% 的 KC 重新隨機接線 |
| 學到的記憶（KC→輸出神經元的權重） | 積極度、多空傾向、偏好的訊號 | ❌ 子代出生時記憶歸零，要靠自己的經驗重新學 |

### 實際資料（淘汰賽 36 隻果蠅、20 組親子）

| 比較 | 親子之間 | 隨機兩隻之間 | 親子相似程度 |
|---|---|---|---|
| 學習速度差異 | 0.092 | 0.406 | 高 77% |
| 探索雜訊（冒險心）差異 | 0.152 | 0.516 | 高 70% |
| 記憶痕跡（記性）差異 | 0.078 | 0.247 | 高 68% |
| KC 稀疏度（專注）差異 | 0.161 | 0.443 | 高 64% |
| 同一段行情中「不動」比例的差距 | 8.1% | 13.7% | 行為也比較像 |
| 個性類型相同（聯賽中 11 組親子） | 6 / 11（55%） | 約 27% | 大約是隨機的 2 倍 |

- 傳承明顯的一家：淺酌（衝動多頭）→ 托爾（長記性）→ 蘿蔔（長記性），祖孫三代記性都偏長。
- 也有「歹竹出好筍」：缺口（衝動多頭）的兩個孩子，卷卷維持衝動多頭，鐵皮人卻變成佛系觀望。因為行為取決於記憶，而記憶不遺傳。

目前**聯賽只有淘汰、沒有繁殖**，繁殖只發生在淘汰賽。如果想看家族在聯賽中延續，可以新增「每季由前幾名產下子代補位」的規則。

## 3. 賽季規則可以調整嗎？可以改投資上市 2000 多檔個股嗎？

### 為什麼不能直接改進行中的聯賽

聯賽每天從開賽日重新播放。如果中途改規則，整個賽季的歷史都會用新規則重算，第 1 季的名次也會改變，等於竄改比賽紀錄。

**正確做法是開新一屆**：用 `season-create` 建立新聯賽，可以指定選股範圍與資金規則，並讓上一屆結束時的存活果蠅帶著記憶參賽。第 2 屆就是這樣建立的：

```sh
python -m flyarena season-create season2-top150 --title "第 2 屆｜市值前 150 大" --start 2026-10-01 --veterans-from survivors-2026
```

老將不需要手動匯出：新一屆開賽時，程式會自動重播上一屆到結束日，取出當時存活果蠅的大腦；新秀補到參賽總數（預設 16 隻）。上一屆的暱稱、個性與你改過的內容也會沿用。

### 可以調整的規則

| 類別 | 設定 | 範例 |
|---|---|---|
| 投資標的 | `symbols` | 權值股、ETF、自選個股、上櫃（`.TWO`） |
| 資金 | `capital`、`order_value`、`max_position_value` | 本金 100 萬、單筆 5 萬、單檔上限 20 萬 |
| 交易頻率 | `trade_every_days` | 每天、每週（5）、每月（20） |
| 交易成本 | `fee_discount`、`odd_lot` | 手續費 6 折、只能整股 |
| 獎懲 | `reward.mode`、`horizon_days` | 看 5 天或 20 天後的結果、依每日資產漲跌 |
| 賽制 | `--season-days`、`--eliminate`、`--min-survivors` | 每月淘汰 2 隻、最後剩 3 隻 |
| 評分 | `tournament.score` | sharpe、return、hit_rate（命中率）、calmar（報酬／回撤） |
| 繁殖 | 尚未支援聯賽 | 每季前幾名產下子代 |

### 擴大到上市 2000 多檔：可行，但要先解決這些問題

| 問題 | 影響 | 解法 |
|---|---|---|
| 資料來源 | Yahoo 要逐檔抓 2000 次，雲端伺服器很容易被限流 | 改用證交所每日全市場資料（一次抓全部）；歷史資料一次性回補；上櫃另抓櫃買中心 |
| 運算量 | 目前每個決策約 0.4 毫秒，16 隻 × 2000 檔 × 250 天 ≈ 800 萬次決策，一年約 50 分鐘，而且每天從頭重播會越來越久 | 全市場用矩陣批次計算；每天存檔、接續前一天，不再從頭重播 |
| 資金分配 | 100 萬、單筆 10 萬最多約 10 檔，果蠅不可能照顧 2000 個訊號 | 新增選股機制：每天只買果蠅「最想買」的前 N 檔 |
| 流動性 | 小型股成交量低，還有處置股、全額交割股、漲跌停鎖死買不到 | 設成交量門檻，排除處置與全額交割股 |
| 倖存者偏差 | Yahoo 查不到已下市股票，回測會高估報酬 | 使用包含下市股票的資料源 |
| 還原股價品質 | 小型股除權息還原更容易出錯 | 多資料源交叉檢查 |

**分階段進行**：第 2 屆（2026-10-01 開賽）先用上市市值前 150 大（近似 0050＋0051 成分股，排除創新板），搭配「每天最多新買 3 檔」的選股機制；確定跑得動、結果有意義，再擴大到全上市。

## 4. 果蠅看得懂日 K 圖嗎？還有什麼能力？

### 牠不是在「看圖」，比較像在「聞味道」

果蠅不會看到 K 線圖的畫面。每天收盤後，程式先把日 K 資料算成 17 個數值，每個數值再交給 5 顆感覺神經元，總共 85 個輸入，組成一種當天市場的「氣味」：

| 類別 | 訊號 |
|---|---|
| 價格動能 | 1、3、5、10、20、60 日報酬 |
| 位置 | 20 日、60 日區間中的位置；20 日、60 日均線乖離 |
| 波動與量 | 20 日波動度、量比（5 日均量／20 日均量）、開盤跳空 |
| 大盤 | 加權指數 1、5、20 日報酬；個股 20 日相對大盤強弱 |

### 牠看不到的東西

- K 棒形狀：上下影線、實體長短、吞噬或十字線這類型態
- 盤中走勢、五檔掛單、成交明細
- 新聞、財報、月營收
- 三大法人買賣超、融資融券

### 已經驗證的能力（訊號反應測試）

| 能力 | 實驗結果 |
|---|---|
| 聯想學習：做對給獎勵、做錯給懲罰，學會對應 | 正確率從 32%（亂猜）升到 100%；凍結的果蠅一直是 32% |
| 反轉學習：規則顛倒後重新學 | 先掉到 58%，再回升到 92% |
| 學得到重點 | 訓練後反應最強的正好是訓練用的 4 個訊號，其他訊號接近 0 |

另外模型設計上有「遺忘」：記憶會依 `weight_recovery` 參數慢慢回到原點，但這項還沒有做專門的實驗驗證。

### 限制

- 記憶痕跡只延續幾天，沒有長期規劃，也不會設停損。
- 每檔股票獨立判斷、單筆金額固定，不會做資金配置。
- 學到的是「某種氣味 → 某個動作」的關聯，不是理解公司或市場。
- 在聯賽裡還**沒有**預測方向的證據：存活果蠅的判斷命中率和 IC 都接近或低於隨機。

### 可以增加的感官

| 新感官 | 難度 | 說明 |
|---|---|---|
| K 棒形狀（實體比例、上下影線、型態） | 容易 | 從現有日 K 資料就能算，直接加成新的「氣味」 |
| 三大法人買賣超 | 中 | 證交所每天公布，免費 |
| 融資融券餘額 | 中 | 證交所每天公布，免費 |
| 月營收 | 中 | 每月公布一次，要處理公布時間，避免偷看未來 |
| 真正「看圖」 | 困難 | 像 stonkfly 把 K 線畫成圖片、輸入視覺神經；需要視覺迴路模型，和目前的蘑菇體設計差很多 |
